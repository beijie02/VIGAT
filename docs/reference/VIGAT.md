# VLM-guided gene activity quantification for one sample

Draws TSS-centered ATAC coverage plots for each marker gene, asks a
vision-language model to select one compact genomic window per gene, and
counts fragments in those windows to build a gene-by-cell count matrix.
Nothing is written to disk; everything is returned as R objects.

## Usage

``` r
VIGAT(
  obj,
  genes,
  tissue,
  species = "human",
  cluster_col = NULL,
  min_atac_cluster_cells = 50,
  openai_model = "gpt-5.5",
  return_intermediates = FALSE,
  return_highlighted_plots = FALSE
)
```

## Arguments

- obj:

  A processed Signac Seurat object with an ATAC assay and gene
  annotation. Set Idents(obj) to the desired ATAC clustering before
  calling if needed.

- genes:

  Character vector of marker gene names.

- tissue:

  Tissue label injected into the API prompt (e.g. "PBMC").

- species:

  Species label injected into the API prompt (e.g. "human"). Set to NULL
  to omit from prompt.

- cluster_col:

  Optional. Name of a meta.data column to use as the ATAC cluster
  assignment. If NULL (default), Idents(obj) is used.

- min_atac_cluster_cells:

  Clusters with fewer cells than this are excluded. Default: 50.

- openai_model:

  OpenAI model name. Default: "gpt-5.5".

- return_intermediates:

  Logical. If TRUE, also return the intermediate results: TSS info,
  overlapping peaks, the coverage plots sent to the model, the prompt,
  the full API response and run information. Default: FALSE.

- return_highlighted_plots:

  Logical. If TRUE, also return one coverage plot per gene with the
  selected window highlighted. Default: FALSE.

## Value

A named list:

- vigat_windows:

  GRanges containing VIGAT-selected genomic windows.

- vigat_window_df:

  Data frame containing the selected genomic windows.

- count_matrix:

  Sparse gene-by-cell raw ATAC count matrix generated by counting
  fragments overlapping the VIGAT-selected windows using
  [`Signac::FeatureMatrix()`](https://stuartlab.org/signac/reference/FeatureMatrix.html).

- diagnostics:

  List containing `raw_response`, `genes_found`, and `genes_skipped`.

- intermediates:

  Only if `return_intermediates = TRUE`: list with `tss_info`,
  `overlapping_peaks`, `coverage_plots` (named list of ggplot objects),
  `prompt`, `api_response` and `api_run_info`.

- highlighted_plots:

  Only if `return_highlighted_plots = TRUE`: named list of ggplot
  objects, one per gene.

## API key

This function reads the OpenAI API key from the `OPENAI_API_KEY`
environment variable. Set it before calling the function:

    Sys.setenv(OPENAI_API_KEY = "your_key_here")

or add it to your `~/.Renviron` file:

    OPENAI_API_KEY=your_key_here

## Examples

``` r
if (FALSE) { # \dontrun{
Sys.setenv(OPENAI_API_KEY = "your_key_here")
Idents(obj) <- "ATAC_snn_res.0.8"
res <- VIGAT(
  obj     = obj,
  genes   = c("INS", "GCG", "SST"),
  tissue  = "Islet",
  species = "human"
)
res$vigat_window_df

# Keep the highlighted plots and save them yourself
res <- VIGAT(obj, genes = c("INS", "GCG"), tissue = "Islet",
             return_highlighted_plots = TRUE)
for (g in names(res$highlighted_plots)) {
  ggplot2::ggsave(paste0(g, "_vigat.png"), res$highlighted_plots[[g]],
                  width = 7, height = 7, dpi = 150)
}
} # }
```
